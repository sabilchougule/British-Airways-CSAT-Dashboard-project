Project Title: British Airways Reviews Analysis Dashboard

Tools Used: Tableau, Excel

Objective: Analyze British Airways customer reviews to identify trends in ratings, traveller preferences, aircraft performance, and geographic distribution.

Key Insights:
- Built three interactive dashboards covering executive overview, customer & aircraft analysis, and geographic insights.
- Analyzed review trends, seat type ratings, traveller types, aircraft popularity, and country-wise performance.
- Designed a clean, professional dashboard using a consistent color theme for clear business insights.
